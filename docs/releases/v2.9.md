# TABaTAB Cash 2.9

- Le menu contextuel des favoris ouvre aussi le dossier dans l’Explorateur Windows.
- Les couleurs des dossiers de l’arborescence sont maintenant rendues visiblement, avec des choix prédéfinis plus vifs.
- Le plein écran décode les HEIC/HEIF avec Pillow-Heif afin d’afficher les pixels au lieu d’une image noire.
- Les doublons s’affichent dans une fenêtre française, organisée par groupes, avec miniatures et informations lisibles en lignes séparées et en gras.
- Les boutons Vidéos et ZIP utilisent le même style, avec un fond vert lorsqu’ils sont activés.
- Les contrôles de tri sont plus visibles.

Le ZIP portable Windows et son empreinte SHA-256 sont joints à cette release. Les préférences personnelles sont exclues de l’archive.
